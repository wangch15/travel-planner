# 查停車

**只有自駕行程需要。** `trip.config` 的 `transport` 沒有 `drive` 就跳過。

目標：填好 `PLACES[key].parking`。

## 每個景點都要查

自駕行程最常出錯的不是路線，是「到了發現沒地方停車」。

| 要查 | 填進 |
|---|---|
| 官方或最近的合法停車場名稱 | `parking.name` |
| 停車場座標 | `parking.lat`／`parking.lng`（**必填**） |
| 費用 | `parking.fee` |
| 注意事項 | `parking.note` |
| 給 Maps 搜尋的字串 | `parking.gq` |

座標很重要：有 `parking` 的地點，頁面上的導航連結會指向**停車場**而不是景點本身，
而且會出現在每日頁尾的停車彙整表。

## 注意事項要寫什麼

寫「到了才會後悔不知道」的事：

- 旺季幾點會滿（「旺季上午容易客滿，晚到請往河對岸的停車場找位」）
- 車輛管制（「溫泉街禁止一般車輛進入，需停在山下共同停車場」）
- 單行道、窄路、高度限制
- 只收現金、要投幣
- 營業時間比景點短（停車場關了車還在裡面）

## 查不到怎麼辦

不要猜。在 `parking.note` 或地點的 `note` 寫「停車資訊待確認」，
並推進 `CHECKLIST`：「出發前確認 X 的停車方式」。

住宿的停車位**一定要問**：很多小旅館沒有停車場，或要另外收費、要事先預約。
這是 `CHECKLIST` 的常客。
