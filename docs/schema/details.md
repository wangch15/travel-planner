# `details.js`

## 這個檔負責什麼

每個地點的詳細說明，點名稱打開的燈箱就是讀這裡。

匯出一個物件，key 對應 `PLACES` 的 key：`module.exports = { [placeKey]: { … } };`

`cat` 不是 `hub` 的地點一律要有一筆。`hub` 有寫就驗、沒寫不擋。

## 欄位表

| 欄位 | 必填 | 型別 | 說明 |
|---|---|---|---|
| `summary` | ✔ | string | **至少 40 字。** 這是什麼、為什麼值得去、去了會看到什麼。支援 `**粗體**`。 |
| `highlights` | ✔ | string[] | **至少 2 點。** 支援 `**粗體**`。 |
| `stay` | ✔ | string | 建議停留時間，例如 `2 小時`、`1 晚`。 |
| `info` | ✘ | [string, string][] | 實用資訊表，每列是 `[標籤, 內容]`。內容支援 `**粗體**`。 |
| `refs` | ✔ | object[] | `{ t: 標題, u: 網址 }`，至少一筆，網址必須是 `http://` 或 `https://`。 |
| `dining` | ✘ | boolean | 這是餐飲地點。燈箱的標題會變成「吃什麼・怎麼安排」，註記改讀 `DINING.checked`。 |

## 完整範例

```js
module.exports = {
  yamadera: {
    summary: '立石寺建於西元 860 年，從山門到奧之院共一千零十五階石階，沿途穿過杉木林與岩壁上的堂宇，登頂後的五大堂可以俯瞰整個山谷。',
    highlights: [
      '**開山堂與五大堂**：懸在岩壁上的木造建築，是整條石階最好的展望點。',
      '**根本中堂**：山門前的本堂，裡面的不滅法燈自開山以來持續燃燒。',
    ],
    stay: '2 小時',
    info: [
      ['參拜時間', '一般為 08:00–16:00，冬季縮短；出發前以官網為準。'],
      ['入山費', '成人數百日圓等級，現場現金支付。'],
    ],
    refs: [{ t: '立石寺 官方網站', u: 'https://www.rissyakuji.jp/' }],
  },
};
```

## 常見錯誤

- `DETAILS.xxx summary 太短` — 少於 40 字。把「為什麼值得去」寫清楚，不要只寫名稱。
- `DETAILS.xxx highlights 不足 2 點` — 至少兩點。
- `DETAILS.xxx 缺 refs` / `ref 網址不合法：ftp://…` — 每個事實都要有可查的來源，而且要是 http(s)。
- `DETAILS.xxx info 每列需為 [標籤, 內容]` — `info` 是二元陣列的陣列，不是物件。
- `DETAILS.xxx 引用未知地點` — key 在 `PLACES` 裡不存在（或拼錯）。
