# Desktop 0.1.16

## 範圍

修復桌面發布工作目錄、失敗後遠端核對的暫存檔生命週期；總覽頁尾與燈箱註記填滿容器；地圖標籤可穿透指標事件；地圖改以 Cmd/Ctrl 加滾輪縮放。

全程總覽新增獨立預約提醒，以 `OVERVIEW.reservations` 的明確地點、日期與說明呈現。沿用現有列表、日期按鈕與詳情燈箱，不猜測自由文字中的預約意圖。選用欄位不影響舊行程。完成勾選依穩定 id 存在本機，與行前清單分開。
