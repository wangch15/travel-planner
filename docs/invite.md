# 傳給朋友的邀請訊息

這一頁是**給模板作者用的**。把下面灰底區塊的內容整段複製，用 LINE／email 傳給想做行程網頁的朋友就好。

他們不需要看懂這一頁，也還不需要能打開這個 repo。

---

## 你（作者）要先做的兩件事

1. 請朋友給你他的 **GitHub 帳號名稱**
2. 到 repo 的 **Settings → Collaborators → Add people** 把他加進來

加完之後，把下面那段傳給他。

---

## ⬇️ 從這裡開始整段複製給朋友 ⬇️

---

嗨，要做行程網頁的話，照這個順序走就好。**你不需要懂程式**，大部分的事你的 AI 助手會幫你做。

### 第一步：辦兩個帳號（這兩個只能你本人辦）

| 平台 | 網址 | 要做什麼 | 什麼時候要 |
|---|---|---|---|
| **GitHub** | [github.com](https://github.com) | 註冊，然後把你的**帳號名稱**告訴我 | 現在就要 |
| **Cloudflare** | [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) | 註冊就好，其他不用設定 | 最後要上線時才用到，可以晚點辦 |

兩個都是**免費**的，不用填信用卡。

辦好 GitHub 後告訴我帳號名稱，我會把你加進專案。你會收到一封邀請信或 GitHub 通知，**記得點進去按接受**。

### 第二步：準備一個「能操作你電腦」的 AI 助手

要用可以在你電腦上執行指令的那種，例如 **Claude Code**、**Codex CLI**、**Gemini CLI**。
一般的網頁版聊天機器人做不了這件事（它們不能碰你的電腦）。

### 第三步：把下面這段貼給你的 AI

這一步是讓它幫你把電腦環境準備好。**你不用先裝任何東西**，缺什麼它會幫你裝。

```text
我要用朋友給我的一個工具做旅程網頁，但我電腦上沒有裝過任何開發相關的東西。
請你先幫我把環境準備好，一步一步來，每一步用白話告訴我你在做什麼。

1. 檢查我的電腦有沒有下面這些，沒有的話幫我安裝
   （你能自己裝就自己裝；需要我點什麼就停下來告訴我）：
   - Node.js，要 20 版以上
   - git
   - gh（GitHub 官方的命令列工具）

2. 幫我設定 git 的使用者名稱與 email，用我的 GitHub 帳號資料。

3. 幫我跑 gh auth login，讓我登入 GitHub。
   會跳出瀏覽器要我按同意，我自己按，你告訴我該按哪裡就好。

4. 最後用 gh auth status 確認我確實登入了，然後告訴我「環境準備完成」。

補充資訊：
- 我的作業系統是：（在這裡填 Windows 或 Mac）
- 我的 GitHub 帳號是：（在這裡填你的帳號名稱）

規則：
- 不要假設我懂任何術語，看到不懂的我會問你。
- 任何一步失敗或卡住，直接告訴我卡在哪裡、需要我做什麼。不要猜，也不要跳過。
```

### 第四步：等它說「環境準備完成」之後

打開這個連結（要先在瀏覽器登入 GitHub）：

**https://github.com/wangch15/travel-planner**

照那一頁上的說明，複製第二段 prompt 貼給你的 AI，就可以開始做行程了。

---

## 為什麼要分成兩段 prompt

第三步那段（環境準備）**不需要碰這個 repo**，所以在他還沒被加進協作者、還打不開 repo 的時候就能先跑。

等環境好了、邀請也接受了，他才用得到 README 上那段（下載專案 → 讀 `AGENTS.md` → 跑 `tp-setup`）。

兩段分開的好處：環境問題與權限問題不會混在一起，卡住的時候比較好判斷是哪一種。

## 哪些事 AI 不能代勞

不管 prompt 怎麼寫，這幾件事一定要本人做：

- 註冊 GitHub 與 Cloudflare 帳號（要收驗證信，可能還有兩步驟驗證）
- 接受協作者邀請
- 在瀏覽器上按「同意授權」（`gh auth login` 與 `wrangler login` 都會跳這個）
- 安裝 AI 助手本身

除此之外——檢查環境、安裝 Node／git／gh、設定 git、fork、clone、`npm install`、產地圖、抓照片、部署——**都可以交給 AI**。
