# 找照片

目標：填好 `photos.json`，然後交給 `tp-photos` 抓檔。
欄位定義見 `docs/schema/photos.md`。

## 授權規則（`npm run check` 會擋）

**只收兩種：**

1. **Wikimedia Commons 的 CC 或 Public domain 授權**
   填 `title`（Commons 檔名）、`artist`、`license`、`page`（檔案頁面連結）。
   `license` 必須含 `CC` 或 `Public domain`，否則 check 不過。

2. **官網照片，並標明來源**
   填 `url`（圖片網址）與 `credit`（例如「© 某某官方網站」），`page` 選填。

**授權不明的一律不要收。** 這不是可以通融的地方——
這個網站雖然不被搜尋引擎收錄，但拿到網址的人都看得到。

## 怎麼在 Commons 找

1. 到 commons.wikimedia.org 搜尋地點的**當地語言名稱**（比英文名好找）。
2. 點進檔案頁面，看右下角的授權欄位。
3. 確認不是「僅供編輯使用」或「需授權」這類限制。
4. 記下完整檔名（含副檔名）、作者、授權、檔案頁面網址。

搜尋技巧：找不到就搜尋更大的範圍（地區名而不是單一建築名），
或看該地點的 Wikipedia 條目用了哪些圖。

## 挑哪一張

- 一個地點一到兩張就夠，不用多。
- 選看得出「去了會看到什麼」的，不要選空景或細節特寫。
- 橫幅比直幅適合燈箱。
- 避免有明顯人臉的照片。

## 填好之後

跑 `npm run photos -- <slug>`，見 `tp-photos`。

沒有合適照片的地點就不要放——燈箱會顯示「這個地點沒有可用的免費授權照片」，
那是正常的，比放一張來路不明的圖好。
