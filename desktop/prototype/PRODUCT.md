# Travel Planner desktop prototype

本機旅程工作台，主要使用者為非技術背景的行程擁有者。首版 Windows 原生與 macOS，能接手既有私人專案，保留 CLI。

2026-09-22 使用者確認的本次需求：中央固定聊天，左側旅程 sidebar 可收合，右側 preview 可開關；專案管理進入獨立設定頁；新增旅程用 modal 問基本資料；使用者訊息靠右呈現對話框。

本次功能仍是原型：真實專案唯讀檢查，修改使用假資料與固定回覆；不冒充已串接 AI、真實預覽、發布或備份。設定頁依真實能力顯示可用狀態。新旅程只建立記憶體中的示範資料。

使用者提供三份正式 SVG；保留位元內容，不改比例、顏色或漸層。桌面與網頁工作台共用品牌資產，為不支援 SVG 的平台匯出 PNG／ICO／ICNS。既有行程網站的個別設定不屬於本次桌面介面改動。
